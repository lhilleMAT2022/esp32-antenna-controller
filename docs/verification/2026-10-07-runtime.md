## Hardware reporting acceptance

Executed using the project virtual environment:

```powershell
.\.venv\Scripts\python.exe tests/hardware_runtime_smoke.py --gateway-port COM10 --node1-port COM11 --node2-port COM7
```

- Both nodes acknowledged each global mode request through CYD/ESP-NOW.
- Continuous: seven status and seven raw-sensor reports per node in a
  seven-second RF observation; intervals matched one second.
- Normal: two status and two raw-sensor reports per node in 22 seconds;
  intervals matched ten seconds. Each USB node supplied 22 of each at 1 Hz.
- Quiet: commanded for 66 seconds. During the 62-second observation after
  acknowledgment, each node sent exactly one radio heartbeat and no raw or
  corrected sensor reports. Each USB node supplied 62 status and raw reports.
- Both nodes automatically returned to normal at expiry. The test restored
  normal explicitly and confirmed both acknowledgments.
- CYD emitted protocol-4 gateway clock reports. Both node UTC clocks advanced
  and stayed within the test's two-second PC sanity bound. Across periodic
  reports, node minus CYD receipt offsets ranged from -17 to -6 ms for N1 and
  -17 to -4 ms for N2. These include one-way delay, not just clock drift.
